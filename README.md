**CodeCure AI** is an end-to-end, machine learning-powered clinical decision support dashboard developed to predict and combat antibiotic resistance. 

By utilizing clinical metadata and robust gradient-boosted models (**XGBoost**), the system provides physicians with estimated pathogen susceptibility to various treatments, alongside dynamic tradeoff recommendations balancing **Efficacy**, **Toxicity**, and **Cost**.

---

## ✨ Features

- **Predictive Diagnostics:** Accurately estimate if an isolated pathogen will be *Resistant* or *Susceptible* to a targeted antibiotic based on real patient demographics.
- **Top Alternative Recommendations:** If the primary targeted antibiotic shows high risk, the AI Engine returns the top 3 best clinical alternatives categorized by success probability and risk tradeoffs.
- **Interactive Antibiograms:** Visualize comprehensive patient-specific susceptibility profiles across the entire modeled pharmaceutical armamentarium.
- **Explainable AI (XAI):** See exactly *why* the model made its decision—with interactive charts mapping out the influence of key clinical risk factors.
- **3D Molecular Conformers:** View real-time 3D rendered models of targeted antibiotics via direct PubChem API integration.
- **Clinical Exporting:** Generate a markdown summary log of the AI assessment for immediate record-keeping.

## 🚀 Installation & Local Setup

If you wish to run the dashboard locally on your machine, follow these steps:

**1. Clone the repository**
```bash
git clone https://github.com/your-username/codecure-antibiotic-ai.git
cd codecure-antibiotic-ai
```

**2. Create and activate a Virtual Environment (Optional but Recommended)**
```bash
python -m venv venv
# On Windows:
venv\Scripts\activate
# On Mac/Linux:
source venv/bin/activate
```

**3. Install Dependencies**
```bash
pip install -r requirements.txt
```

**4. Launch the Dashboard**
```bash
streamlit run app/streamlit_app.py
```

## 📊 Model Training Pipeline

If you want to completely retrain the statistical models from scratch over new data inputs:
1. Ensure your new `Bacteria_dataset_Multiresictance.csv` is correctly placed in `data/`.
2. Execute the training script from the root directory:
   ```bash
   python src/train.py
   ```
3. A newly compiled `model.pkl` will be safely routed directly to the `model/` directory, and visualizations will update appropriately.
